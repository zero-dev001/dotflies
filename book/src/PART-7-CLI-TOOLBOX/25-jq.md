# JSON Processing: jq

> A lightweight, flexible command-line JSON processor -- the sed and awk of structured data.

## Your Setup

jq is installed via Homebrew in the base Brewfile:

```ruby
brew "jq"
```

It is most commonly used in combination with **curl** for API exploration and with shell scripts that consume JSON output from tools like `gh`, `docker`, and cloud CLIs. Any command that produces JSON can be piped directly to jq.

## Core Concepts

jq operates on a stream of JSON values. You write a **filter expression** that transforms input JSON into output JSON. Filters can be chained with the pipe operator `|`, just like Unix commands. The simplest filter is `.` (the identity), which pretty-prints the input with colour.

Key mental model:

- `.` means "the current value"
- `.key` descends into an object
- `.[]` iterates over array elements or object values
- `|` passes output from one filter to the next
- Everything in jq is an expression that produces zero or more outputs

### Type System

jq works with the same types as JSON: objects, arrays, strings, numbers, booleans, and null. It adds no new types but provides rich operators for transforming between them.

## Essential Commands

| Command | Purpose |
|---|---|
| `jq '.'` | Pretty-print JSON with syntax colouring |
| `jq '.key'` | Extract a top-level field |
| `jq '.key.nested'` | Extract a nested field |
| `jq '.array[0]'` | First element of an array |
| `jq '.array[-1]'` | Last element of an array |
| `jq '.array[2:5]'` | Array slice (indices 2, 3, 4) |
| `jq '.array[:3]'` | First three elements |
| `jq '.array[-2:]'` | Last two elements |
| `jq '.[]'` | Iterate over all elements |
| `jq '.key1, .key2'` | Output multiple fields |
| `jq -r '.name'` | Raw output (no quotes around strings) |
| `jq -c '.'` | Compact output (one line per object) |
| `jq -e '.key'` | Exit with error if result is null or false |
| `jq -s '.'` | Slurp: read entire input as one array |
| `jq -n '{}'` | Null input: generate JSON from nothing |
| `jq --arg name "val" '.'` | Pass a string variable into the filter |
| `jq --argjson num 42 '.'` | Pass a JSON value variable into the filter |

## Filter Reference

### Selection and Filtering

| Filter | Purpose |
|---|---|
| `select(.key == "value")` | Keep only objects where condition is true |
| `select(.age > 30)` | Numeric comparison |
| `select(.name \| test("pattern"))` | Regex match |
| `select(.tags \| contains(["important"]))` | Array contains check |
| `select(has("key"))` | Object has a specific key |
| `select(.key != null)` | Filter out null values |

### Transformation

| Filter | Purpose |
|---|---|
| `map(.field)` | Apply expression to each array element |
| `map(. + 1)` | Increment every element |
| `map(select(.active))` | Filter array, keep active items |
| `sort_by(.field)` | Sort array of objects by field |
| `group_by(.field)` | Group array elements by field value |
| `unique_by(.field)` | Deduplicate by field |
| `reverse` | Reverse an array |
| `flatten` | Flatten nested arrays one level |
| `limit(n; .[])`  | Take first n elements from iterator |
| `keys` | Get object keys as an array |
| `values` | Get object values as an array |
| `length` | Count elements in array or keys in object |
| `type` | Return the JSON type as a string |
| `to_entries` | Convert object to array of {key, value} pairs |
| `from_entries` | Convert {key, value} array back to object |

### Construction and String Handling

| Filter | Purpose |
|---|---|
| `{newkey: .oldkey}` | Build a new object |
| `[.items[].name]` | Build a new array |
| `"\(.key) is \(.value)"` | String interpolation |
| `.key // "default"` | Alternative operator (if null, use default) |
| `split(",")` | Split string into array |
| `join(",")` | Join array into string |
| `ascii_downcase` | Lowercase a string |
| `ltrimstr("prefix")` | Remove a prefix |
| `rtrimstr("suffix")` | Remove a suffix |
| `gsub("old"; "new")` | Global string substitution |

### Conditionals and Reduction

| Filter | Purpose |
|---|---|
| `if .x then .a else .b end` | Conditional expression |
| `reduce .[] as $x (0; . + $x)` | Fold/reduce over array |
| `.[] \| if .type == "a" then .val else empty end` | Conditional with empty to skip |

## Practical Recipes

### Pretty-print a curl response

```bash
curl -s https://api.github.com/repos/neovim/neovim | jq '.'
```

### Extract specific fields from API data

```bash
curl -s https://api.github.com/repos/neovim/neovim | \
  jq '{name: .name, stars: .stargazers_count, language: .language}'
```

### Filter an array of objects

```bash
echo '[{"name":"Alice","age":30},{"name":"Bob","age":25}]' | \
  jq '[.[] | select(.age > 27)]'
```

Result: `[{"name":"Alice","age":30}]`

### Transform a list of objects into a summary

```bash
curl -s https://api.github.com/users/octocat/repos | \
  jq '[.[] | {name: .name, stars: .stargazers_count}] | sort_by(.stars) | reverse'
```

### Create CSV output from JSON

```bash
curl -s https://api.github.com/users/octocat/repos | \
  jq -r '.[] | [.name, .stargazers_count, .language] | @csv'
```

The `@csv` format filter handles quoting and escaping for proper CSV.

### Count items by category

```bash
echo '[{"type":"bug"},{"type":"feature"},{"type":"bug"}]' | \
  jq 'group_by(.type) | map({type: .[0].type, count: length})'
```

### Merge two JSON files

```bash
jq -s '.[0] * .[1]' base.json overrides.json
```

The `*` operator recursively merges objects. The `-s` (slurp) flag reads both files into a single array.

### Update a nested value

```bash
jq '.config.timeout = 30' settings.json > settings-new.json
```

jq does not edit files in place. Write to a new file and rename, or use `sponge` from moreutils.

### Process NDJSON (newline-delimited JSON)

```bash
# Each line is a separate JSON object -- jq handles this natively
cat events.ndjson | jq 'select(.level == "error")'
```

### Use shell variables inside jq

```bash
name="Alice"
jq --arg n "$name" '.[] | select(.name == $n)' data.json
```

Always use `--arg` to inject shell variables. Never interpolate shell variables directly into jq expressions -- it breaks on special characters and is a security risk.

## Advanced Usage

### Building Complex Pipelines

jq filters compose naturally. Think of each `|` as passing the current value(s) to the next stage:

```bash
curl -s https://api.github.com/orgs/github/repos?per_page=100 | \
  jq '[.[]
    | select(.language != null)
    | {name, language, stars: .stargazers_count}]
    | group_by(.language)
    | map({language: .[0].language, count: length, total_stars: map(.stars) | add})
    | sort_by(.total_stars)
    | reverse'
```

This pipeline: filters out repos with no language, extracts fields, groups by language, counts repos and sums stars per language, then sorts by total stars descending.

### Defining Functions

```bash
jq 'def double: . * 2; [.[] | double]' <<< '[1,2,3]'
# Output: [2,4,6]
```

### The `env` Object

jq can access environment variables directly:

```bash
export API_KEY="secret"
jq -n 'env.API_KEY'
```

### Error Handling with `try-catch`

```bash
echo '{"a":1}' | jq 'try .b.c catch "missing"'
# Output: "missing"
```

### Working with gh CLI Output

The GitHub CLI outputs JSON with `--json`, which pairs perfectly with jq:

```bash
gh pr list --json number,title,author --jq '.[] | "\(.number): \(.title) by \(.author.login)"'
```

Note that `gh` has a built-in `--jq` flag, so you can avoid the pipe entirely.
